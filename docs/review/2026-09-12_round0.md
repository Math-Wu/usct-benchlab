## Canonical imports

Use `usctbench.operators.straight_ray`, `.eikonal`, and `.ray_born` internally.
The direction-based modules re-export the identical objects for compatibility.
Volume-integral and optional CUDA helpers also have canonical paths so the
physical implementations do not import their compatibility wrappers. No CUDA
dependency becomes mandatory. The FWI implementation and MATLAB resources remain
in place; its Eikonal import is canonical.

Compatibility policy: no removal now. Deprecation notices begin in 0.2; removal
cannot precede 1.0, two minor versions and 90 days of notice, and may be delayed
for active consumers. New implementations belong under physical modules, not
under compatibility directories.

## Recorded stopping semantics

`metrics.stopping` records `optimization_variable`, `update_variable`,
`update_units`, `update_norm`, `update_norm_scope`, `update_normalization`,
`iteration_unit`, `stage_id`, `selected_stage_id`, and `resolved_policy`.
The existing `policy` field remains an identical compatibility copy.
`policy_source` distinguishes new RunControls from legacy parameter defaults.

| Method | Optimization variable | Update statistic state |
|---|---|---|
| Straight CGLS/SIRT/SART | Slowness perturbation | Full slowness, s/m |
| Reduced straight methods | Perturbation coefficients | Full slowness coefficients, s/m |
| Bent | Slowness or perturbation coefficients | Expanded full slowness, s/m |
| Fixed Born | Squared-slowness perturbation | Full squared slowness, s^2/m^2 |
| Nonlinear Born / controlled FWI | Squared slowness | Full squared slowness, s^2/m^2 |
| Attenuation SIRT | Legacy attenuation | Legacy declared Np/m state; frequency provenance remains unspecified |

This round records the *actual* Euclidean L2 calculation. Existing full-grid
norms include fixed exterior pixels even when updates are ROI-restricted. On a
uniform grid a constant cell-volume factor cancels in the relative norm. Reduced
straight methods still use coefficient-grid norms; these are explicitly labeled,
not passed off as expanded physical-grid norms. Moving those calculations to a
fixed physical update domain would change stopping behavior and is not silently
included in this metadata-focused round. No cross-method equivalence is claimed.

RunControls retains `update_rtol=None`, resolves a missing iteration limit from
the method, then intersects caps. Legacy StopPolicy defaults are preserved and
identified, not promoted as defaults for new Agent calls. IRLS stage changes
reset small-update patience without resetting iterations, time or operator work.

The demonstrated attenuation exception is removed: adding an all-ones map created
an arbitrary physical normalization scale. A zero previous state now produces
an undefined relative update (`null`), which cannot trigger update stopping.
Other stopping criteria remain applicable. This does not introduce a reference
frequency or relabel legacy data as a versioned attenuation contract.

External FWI artifacts explicitly report unknown update semantics and unknown
executed policy; result import cannot certify an uninstrumented upstream loop.
Tiny FWI records its fixed step schedule and lack of update stopping. Neither is
misrepresented as an implementation of the online controlled-FWI contract.

on a fixed active-parent set, real/complex Born adjoints, second-order Born
