## 2. 本次实现与数学边界

### 2.1 Siddon 等价 CSR：默认开启的执行优化

原交点和长度系数不变，缓存 CSR 并以同一矩阵的转置实现伴随；保留 `projector_backend: reference`。行/列平方范数先合并同一像素的重复系数再平方，匹配真实矩阵范数。前向与伴随仍在各自命名空间内，没有把重建求解器叫作伴随。

完整 64 通道的成对 CPU 求解循环耗时为 CGLS **2.423 → 0.709 s**、SIRT **4.544 → 0.892 s**、SART **13.749 → 2.656 s**。这些是本机单次成对观察，约 3.4/5.1/5.2 倍循环加速，不是包括所有 setup 的端到端倍率，也不是 A100 测量或统计性能保证。额外 CSR 存储 12,956,968 字节，同时仍保留原交点列表；并非零额外内存。重建数组和停止条件不变，**这不是成像质量收益**。

### 2.2 可选 32² 参数化：改变模型空间，不改变传播网格

令 `delta_s = B a`。B 为非负、保常数、边界复制的双线性基，a 在 32² 网格上，实际声速输出、Siddon 路径和 Eikonal 传播仍在 256² 网格。直线前向/伴随为 `A B` 与 `B^T A^T`；Bent 每次在当前细网格模型重新计算真 Eikonal，其局部线性化为 `J B` 与 `B^T J^T`。不是降采样采集，不是锐化结果，更不是把全波方法改名。

正则保持原细网格的 `L B a`，梯度为 `B^T L^T L B a`，lambda 没有因为参数网格变化而偷偷改量纲。系数慢度满足盒约束，B 的非负与行和为 1 保证细网格慢度也在盒约束内。以 water 配置初始化；不由 GT 或 GT mask 初始化、拟合 offset 或决定更新区。

仅试了预先记录的一种 `[32,32]` 选择，没有巨大网格/正则 sweep；选择动机是减少相对训练路径数过多的未知量，并非由 GT 搜索最优格点数。它是一种显式空间先验，不能凭先验补回真实细节。粗模型暂不支持反演 ROI；粗 Bent 暂不支持非均匀初始化或 CGLS warm start，遇到不支持组合明确报错。

工程近似：原有迭代内 Gaussian 宽度按网格间距换算，名义物理宽度保持，但离散滤波器并不完全等价，粗网格下可能接近恒等。因此这里比较的是完整的模型空间方案，而非声称只改变未知数个数、其余离散先验严格相同。没有在输出图像上添加滤波或锐化。

### 2.3 相位特征：保留负对照，不替换默认

在高频 D 使用源频率 500 kHz 的水参考相位，`tau=(arg(P/Pwater)+2*pi*k)/(2*pi*f)`；原 pulse delay 只决定整数周期 k。预处理逐通道，不做互易平均、跨通道拟合或验证数据驱动调参。原 2,752 个有效通道、权重和划分全部保留。此处相位除频率不是相位的频率导数，仍不是有限频率散射反演。

四种完整实验均恶化：CGLS/SIRT/SART/Bent 的 RMSE 分别为 **30.25673 / 29.32182 / 29.28898 / 29.52617 m/s**，SSIM 分别为 **0.082443 / 0.098822 / 0.099221 / 0.100046**。因此没有继续执行低频相位重建，也没有将其默认启用。单频相位解周仍依赖锚点误差小于半周期的假设，不能声称消除了 multipath 或到时偏差。

### 2.4 修复“失败后仍显示成功”的实际 bug

先注入非有限预测：四方法在第一次或第二次调用出错，共 8 个测试，均复现了不正确状态。原实现可能恢复有限图像却报告 success；Bent 的非有限线搜索预测还可能被误报为线搜索未改善。

修复后，活动通道上的非有限 Eikonal 预测触发 numerical_failure；numerical_failure/linear_solver_breakdown 标为 failed，保留有限回退图仅用于诊断，并写 `recovered_checkpoint_only=true`。没有把回退的初始水图冒充成功反演。8 个故障测试全部通过。

## 4. 验证、停止、预算：不能用单一分数替代

使用包内 receiver_fraction=0.125、seed=42，排除 reciprocal training counterpart。高频训练 2,098 条、接收验证 344 条、为防互易泄漏额外不用 310 条；有效观测总计 2,752。验证接收编号 `[5,26,38,44,53,60,62,63]`。所有高频变体、方法的划分一致；低频各组内也已自动断言一致。验证集已经用于早停和选迭代，所以不是独立 test。

沿用原上限 CGLS120、SIRT200、SART100、Bent20 outer/inner24，600 s 预算、残差目标 0.01 及原 plateau/update 阈值。没有为了获胜放宽预算或选 GT 最优迭代。高频 32² 的停止为：

| 方法 | 选中/完成 | 原因 | logical forward / adjoint |
| --- | --- | --- | --- |
| CGLS | 22/26 | validation_plateau | 27 / 26 |
| SIRT | 200/200 | max_iterations | 201 / 201 |
| SART | 100/100 | max_iterations | 801 / 808 |
| Bent | 3/8 | validation_plateau | 201 / 200 |

所有主比较记录的停止均为 max_iterations 或 validation_plateau，没有达到残差目标；正常算法返回成功只意味着完成了配置流程，不意味着达到指定成像质量。CGLS step、SART sweep、Bent outer 不能直接横比。Bent 的 logical forward 201 包含 1 次初始非线性前向、8 次线搜索和192次 Jv，而不是201次完整多源传播。逐源 marching 次数/FLOP 尚未额外统一计量，本轮保留了 ledger 的真实粒度，不伪造“等计算量”。

验证残差也不是 SOS 质量的充分代理。例如低频 D 的 SART 验证残差从 0.128355 降到 0.099147，但组织 RMSE 从31.45345升至32.35527。高频 Bent 的组织指标改善时，验证残差反而从0.235050略升到0.238136。相位与包络 ToF 本身又不是同一个观测目标，二者残差不用于横向排名，更不与压力残差直接排名。

完整28行 metrics.csv/metrics.json包含组织、full_image、水区RMSE/bias、训练/验证相对残差、selected/completed、stop_reason、时间和算子工作量；每个 result 附带完整 iteration_history。24张迭代/时间曲线保留两种参数化的 train/validation 与选中迭代，另有3张含 GT 的统一灰度比较图。

## 5. 数学核验与尚存模型误差

独立运行的数值审计中，Siddon 内积相对误差 `7.13e-16`，Eikonal `4.63e-16`，复合 AB `0`，JB `3.33e-16`；非线性 Eikonal 中央方向导数相对误差 `2.83e-9`。正则 LB 的伴随和目标函数梯度也通过单元测试。均匀水经既有校准后误差约 `3.39e-21 s`，但这只验证校准一致性。

平界面独立 Snell/Fermat 到时对照：41²、81²、161² 网格相对误差依次 **2.309%、1.511%、0.940%**，随加密下降；没有宣称一阶 marching 已无离散误差，也没有把通过伴随测试等同于物理准确。

最后的 GT 前向诊断未用于反演、选迭代或校正数据：在高频原包络 ToF 的2,752有效通道上，GT经Siddon与Eikonal前向后的非加权到时RMS误差分别 **0.08457 μs、0.08742 μs**，仍显著不为零。此误差混合了有限频带到时特征、几何物理近似与离散误差，不能据此确定单一原因。但证据不支持“只是迭代不够”的解释。
